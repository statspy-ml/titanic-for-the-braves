# Titanic for the Braves

Machine Learning from beginner to advanced, using the Titanic dataset as a continuous case study.

| Tema avançado                   | Como explorar no Titanic                                                                      |
| ------------------------------- | --------------------------------------------------------------------------------------------- |
| **Feature engineering**         | `FamilySize`, `IsAlone`, título do nome, cabine, tarifa por pessoa                            |
| **Missing data**                | imputação simples vs. KNN vs. modelos de imputação                                            |
| **Data leakage**                | mostrar por que imputação, encoding e seleção de features precisam ocorrer dentro do pipeline |
| **Cross-validation**            | K-Fold, Stratified K-Fold, nested CV                                                          |
| **Hyperparameter optimization** | Grid Search, Random Search, Bayesian Optimization                                             |
| **Regularização**               | Ridge, Lasso, Elastic Net e efeito de `C`/`alpha`                                             |
| **Modelos não lineares**        | árvores, Random Forest, Gradient Boosting                                                     |
| **Boosting**                    | XGBoost/LightGBM/CatBoost e comparação com modelos clássicos                                  |
| **Ensemble learning**           | bagging, boosting, stacking e voting                                                          |
| **Interpretabilidade**          | permutation importance, SHAP, PDP, ICE                                                        |
| **Calibration**                 | Brier score, calibration curve, Platt scaling, isotonic regression                            |
| **Class imbalance**             | precision/recall, F1, ROC-AUC, PR-AUC, threshold tuning                                       |
| **Probabilidade**               | previsão de `P(Survived=1)` em vez de simplesmente 0/1                                        |
| **Causalidade**                 | discutir por que importância preditiva ≠ efeito causal                                        |
| **Fairness**                    | investigar diferenças de desempenho entre grupos                                              |
| **Uncertainty**                 | bootstrap, intervalos de confiança e variabilidade entre folds                                |
| **Learning curves**             | entender bias/variance e se mais dados ajudariam                                              |
| **Error analysis**              | descobrir sistematicamente onde o modelo erra                                                 |
| **Model selection**             | comparar modelos sob diferentes métricas e custos                                             |
| **MLOps**                       | pipeline reproduzível, versionamento, validação e tracking de experimentos                    |
